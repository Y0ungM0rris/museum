# Гаврилово-Посадский краеведческий музей – интерактивный гид

Веб-приложение для сенсорного киоска с вертикальным экраном 9:16 (рассчитано на 1080×1920).
Три раздела: **Галерея**, **Личности**, **Викторины**.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы, подключение шрифта Montserrat Alternates и GSAP |
| `styles.css` | дизайн: пастельная бежево-коричневая палитра, анимации |
| `data.js` | **все тексты, фото, люди и вопросы** – редактируйте здесь |
| `art.js` | встроенные иллюстрации (показываются, если фото нет) |
| `app.js` | логика: слайд-шоу, полный экран, викторины |

## Публикация на GitHub Pages

1. Создайте репозиторий, например `museum-guide`.
2. Загрузите все файлы из этой папки в корень репозитория (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/museum-guide/`.

## Как добавить свои фотографии

1. Создайте в репозитории папку `images/` (для портретов – `images/people/`).
2. Положите туда фото (лучше JPG/WebP шириной 1200–1600 px).
3. В `data.js` укажите путь у нужного слайда: `src: 'images/zal-tekstilya.jpg'`
   или у человека: `photo: 'images/people/zhiltsov.jpg'`.

Если фото не загрузится, автоматически покажется иллюстрация из поля `art`.

## Как добавить вопрос

В `data.js` → `QUIZZES` → нужная викторина → `questions`:

```js
{ q: 'Текст вопроса?', o: ['Вариант А', 'Вариант Б', 'Вариант В', 'Вариант Г'], a: 1, note: 'Пояснение к ответу' }
```

`a` – номер правильного варианта, считая с нуля (0 = А, 1 = Б…).

## Режим киоска

- Слайды листаются сами каждые 7 секунд (меняется в `app.js`: `SLIDE_MS`).
- Без касаний 2 минуты приложение возвращается на главный экран (`IDLE_MS`).
- Для интерактивной доски запускайте браузер в режиме киоска (Chrome: флаг `--kiosk`).
- В викторине к уже отвеченному вопросу можно вернуться касанием по шкале прогресса.
- Управление с клавиатуры: ← → – листать, пробел – пауза, Esc – закрыть полный экран.

## Источники фото

Часть фотографий подгружается с Wikimedia Commons (лицензии CC BY-SA и аналогичные, авторы указаны на страницах файлов).
Для работы без интернета скачайте нужные фото в `images/` и поменяйте пути в `data.js`.
